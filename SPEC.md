# interview-online — указатель спецификаций

Актуализировано: 2026-09-23. Каждая фича имеет отдельную спецификацию в `specs/features/`. Этот файл содержит только порядок и статус работ. Исторические материалы в `openspec/` не являются рабочими спецификациями.

## Правила работы

- Перед изменением поведения открыть спецификацию соответствующей фичи. Новое решение кратко записать в неё.
- Для исполнимого поведения сначала написать проверку, затем минимальное исправление и целевые регрессии.
- Для UI-сценариев предпочитать E2E; для прав, миграций и конкурентных сценариев — backend integration tests на PostgreSQL.
- Feature flags остаются выключенными по умолчанию до принятия соответствующего release gate.
- Не менять запущенное локальное приложение пользователя без явной просьбы.

## Очередь завершения

1. Провести продуктовую приёмку запущенного локального командного сценария и исправить найденные дефекты.
2. При многопроцессной выкладке настроить маршрутизацию комнаты к одному realtime-хосту либо межпроцессную доставку событий в целевой инфраструктуре.

## Отложено отдельно

- Native AX automation для проверки macOS/browser lifecycle.
- Phone/mobile browser support; текущая матрица — desktop/tablet.
- Внешние уведомления/email.
- Глобальный каталог чужих команд.
- Чат с кандидатом: текущий «Чат» — внутренний чат команды.
