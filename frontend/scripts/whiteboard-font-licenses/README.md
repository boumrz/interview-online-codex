# Whiteboard font notices

These files accompany the unmodified browser fonts supplied by
`@excalidraw/excalidraw` 0.18.1. Serve this directory with the font assets under
`/whiteboard-assets/font-licenses/`; the editor package's MIT license is separate.

| Family directory | License | Notice |
| --- | --- | --- |
| Assistant | OFL-1.1 | [Assistant.LICENSE.txt](Assistant.LICENSE.txt) |
| Cascadia | OFL-1.1 | [Cascadia.LICENSE.txt](Cascadia.LICENSE.txt) |
| ComicShanns | MIT | [ComicShanns.LICENSE.txt](ComicShanns.LICENSE.txt) |
| Excalifont | OFL-1.1 | [Excalifont.LICENSE.txt](Excalifont.LICENSE.txt) |
| Lilita | OFL-1.1 | [Lilita.LICENSE.txt](Lilita.LICENSE.txt) |
| Nunito | OFL-1.1 | [Nunito.LICENSE.txt](Nunito.LICENSE.txt) |
| Virgil | OFL-1.1 | [Virgil.LICENSE.txt](Virgil.LICENSE.txt) |
| Xiaolai | OFL-1.1 | [Xiaolai.LICENSE.txt](Xiaolai.LICENSE.txt) |

`manifest.json` records the exact hashes of the npm font files and the notice
sources. Copyright notices are retained from those exact font name tables.
Excalifont/Comic Shanns notices come from the pinned Excalidraw source; Virgil's
complete OFL is embedded in the pinned font itself. The other OFL texts are
from the font authors' repositories at the recorded commits/tags.

The unused server-side Liberation font directory is excluded from browser
delivery. Its bundled file identifies itself as version1.05; it must not be
relabeled with the OFL text for modern Liberation releases.
