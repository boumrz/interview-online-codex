# Локальная рабочая область интервьюера

## Why

Сейчас клик интервьюера по строке задачи меняет только выделение в списке и его личные заметки. Центральная рабочая область (брифинг, код и язык) продолжает показывать опубликованный для комнаты шаг. Это создаёт ложное впечатление, что интервьюер перешёл к задаче, хотя фактически он всё ещё смотрит на другую.

Нельзя просто подставить выбранный шаг в существующий совместный редактор: его Yjs-синхронизация и серверная проверка `syncKey` привязаны к единственному опубликованному шагу комнаты. Такое решение может отправить данные предпросмотра в общий редактор или перезаписать код активной задачи.

## What Changes

- Клик интервьюера по задаче будет переключать центральную рабочую область только для этого интервьюера.
- Пока выбранный шаг не опубликован, центральная область будет изолированным предпросмотром только для чтения: сохранённый код, язык и брифинг выбранной задачи. Он не создаёт Yjs-документ и не отправляет события комнаты.
- Для безопасной загрузки данных неактивной задачи появится серверный endpoint только для владельца и интервьюера. Кандидат не сможет получить эти данные.
- При совпадении локального и опубликованного шага сохраняется текущая совместная редактируемая область, управляемая сервером.
- Кнопка публикации получит текст `Переключить` и вид компактного прозрачного синего тега, согласованный с тегом `Активен`.

## Out of Scope

- Редактирование кода или брифинга неактивного шага.
- Изменение протокола Yjs либо распространение содержимого всех задач через SSE.
- Переработка хранения локального выбора с индекса шага на постоянный идентификатор.

## Affected Areas

- Frontend: `RoomPage`, локальный выбор шага, безопасный read-only preview и стили строки задачи.
- Backend: защищённый manager-only снимок сохранённой рабочей области конкретной задачи.
- E2E: изоляция трёх участников, отсутствие публикации при локальном клике, доступы и визуальный контракт тега.
