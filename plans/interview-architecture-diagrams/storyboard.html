P2.4 · ДО РЕАЛИЗАЦИИ

Одна схема для общего обсуждения

Макеты интеграции draw.io в основную область комнаты: переключение, совместная работа, сохранение и просмотр.

Это макеты состояний. Область схемы условно показывает будущий draw.io; его рабочая панель и инструменты остаются стандартными.

Текущий контракт P2.4 · Общий режим комнаты

Поток

Управляющий: Code / Markdown
  → выбирает «Схема» → подтверждение для всех
  → загрузка → пустой холст / сохранённая схема
  → кандидат и интервьюеры редактируют одновременно
  → сохранение → «Сохранено»
                 ↘ разрыв → восстановление → тот же документ
                 ↘ ошибка → повтор → подтверждение
  → finished: кандидат смотрит, управляющий продолжает работу
  → отзыв доступа: документ скрыт, очереди остановлены
Принятые границы: одна схема на интервью; обе формы рисования; текущие права комнаты; статический редактор в InterHub. Дополнительных платформ и платных интеграций нет. Продуктовых вопросов, блокирующих эти макеты, не осталось.

Основные состояния

Проверка переходов

  • Отмена диалога сохраняет текущий режим всех участников.
  • Переключение Code / Markdown / Схема сохраняет документы и собственную историю отмены.
  • «Развернуть схему» освобождает всё окно только у текущего участника; возврат восстанавливает комнату.
  • Боковая панель скрывается независимо от условия; вкладки открывают её снова.
  • Сохранение подтверждается сервером; разрыв и ошибка не очищают холст.
  • Finished кандидат видит просмотр; frozen блокирует изменение всем.
  • Отзыв доступа скрывает документ и игнорирует запоздалые ответы.

Последовательность реализации

  1. Изолированно проверить встроенный draw.io и совместные изменения.
  2. Реализовать сохранение и права через реальные серверные операции.
  3. Подключить холст к обеим проекциям комнаты и существующему переключателю.
  4. Проверить перечисленные состояния, реальные экспорты и независимый scoped review.
