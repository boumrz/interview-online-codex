# METRICS.2 — Локальный дашборд Метрики

Владелец счётчика открывает аудиторию и возвращаемость InterHub на своём компьютере. На Mac двойной щелчок по `Открыть-дашборд-Метрики.command` открывает локальный сервер. Из терминала подходит `node scripts/serve-metrika-dashboard.mjs` и адрес http://127.0.0.1:4175/.

## Поведение и приёмка

- **R-01.** При заданном `METRIKA_OAUTH_TOKEN` сервер использует действующие отчёты API для выбранного периода, закончившегося не позже вчерашнего дня по времени счётчика. Отказ API остаётся видимой ошибкой.
- **R-02.** Без токена сервер читает датированный отчёт из `.local-metrics/snapshot.json`. На экране видны источник, дата получения, счётчик, часовой пояс, точные периоды и ссылка в Метрику. Действие «Перечитать срез» повторно читает файл. Оно не запрашивает свежие данные из Метрики.
- **R-03.** DAU, WAU и MAU считаются по уникальным посетителям за 1, 7 и 30 дней до даты окончания включительно. Общие посетители, визиты, просмотры и новые посетители относятся ко всему указанному периоду. Retention D1/D7/D30 показывает долю новичков, вернувшихся ровно в указанный день, с числителем, знаменателем и датами первого визита зрелых когорт. Отсутствующее измерение отображается как недоступное. Измеренный ноль остаётся нулём.
- **R-04.** Срез и идентификаторы посетителей не публикуются. Файл вне Git и каталога статических ресурсов. Разрешены лишь метаданные отчёта и перечисленные агрегаты. Некорректный или отсутствующий срез даёт безопасную ошибку. Сервер слушает loopback, сохраняет проверку Host и запрет кэширования.
- **R-05.** Команда `node scripts/serve-metrika-dashboard.mjs --export` атомарно сохраняет самодостаточный HTML в `.local-metrics/dashboard.html` с доступом владельца. Офлайн-файл открывается без сервера и показывает источник и дату. После обновления среза команда создаёт новую версию.
- **R-06.** Локальная страница и экспорт содержат отдельный блок перехода в актуальные отчёты счётчика. При открытии файла в часовом поясе Москвы пересчитываются ссылки DAU за вчера, MAU и продуктовых целей за 30 завершённых дней, удержания по дневным когортам новых посетителей за 90 завершённых дней. Все цифры сохранённого среза сохраняют исходное окно. Без JavaScript ссылки используют завершённые окна на дату среза.

- **R-07.** Если в срезе есть сводка предыдущего периода, её даты непосредственно примыкают к основному периоду и содержат столько же дней. Для сравнения и целей интервью видны только подтверждённые измерения. Счётчик целей показывает число срабатываний за указанный основной период.

- **AC-01.** Датированный срез без API открывается и после замены файла показывает новые значения. Доступная нулевая метрика, недоступное измерение и малая когорта подписаны раздельно.
- **AC-02.** При отсутствии файла, ошибке схемы, несовпадении счётчика или незрелой когорте страница объясняет проблему без публикации произвольных полей. Сырые файлы недоступны по HTTP.
- **AC-03.** Токен выбирает существующую страницу с периодами и возможность обновить данные непосредственно из API.
- **AC-04.** Офлайн HTML содержит встроенные стили и ссылку на счётчик. Если новая версия среза недействительна, прежний экспорт остаётся доступен.
- **AC-05.** Открытие файла после московской полуночи и на границе года обновляет ссылку MAU до 30 завершённых дней и ссылку DAU на вчера. Скрипт не запрашивает данные и ограничен хешем CSP.

- **AC-06.** Границы сравнения, нецелый счётчик или неизвестное поле проверяются до показа. Отсутствующие поля целей пропускаются, зарегистрированный ноль виден.

## Проверка

Приёмочные тесты вызывают обработчик настоящего HTTP-сервера для главной страницы,
повторного чтения, отказа по Host, запроса сырого файла, невалидных агрегатов
и выбора live-режима. Числа в тестах синтетические. Набор проверок локальной
Метрики дал 23 PASS из 24, оставшийся сетевой тест блокируется окружением при
привязке loopback (`EPERM`). Запуск приложения и получение данных из аккаунта
проверяются отдельно.
