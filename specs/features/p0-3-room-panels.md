# P0.3 Комната: вкладки и изменение размеров панелей

Цель: редактор остаётся центральной областью без лишней вкладки «Редактор», а вспомогательные области сохраняют доступность и изменяемые размеры.

Статус: реализовано и технически проверено; условие в Code определено [P2.1](p2-1-room-layout-modes.md),
продуктовый просмотр ожидается.
В Chromium для AC-01 проверены доступное имя области и нулевой отступ перед
содержимым при ширине 390 и 1280 px. [Полный регресс предыдущей раскладки](../references/2026-11-12-full-regression-tablet-input.md) — PASS.
Актуализировано: 2026-11-12.

## Границы и требования

Входит: локальная геометрия панелей и доступность четырёх вспомогательных вкладок.
Права, общий режим и доставка документов определяются P2.1/P2.3; изменение размеров
не меняет серверные данные или раскладку других участников.

- **R-01.** Рабочая область во всех режимах открывается сразу с содержимого, без
  дополнительной вкладки, видимого заголовка «Редактор» или места под него.
  Для экранного диктора область сохраняет имя «Редактор».
- **R-02.** Доступны четыре вкладки: шаги, заметки, чат, активность. На широкой
  раскладке вспомогательная панель находится слева от редактора; её четыре вкладки
  остаются в прежнем общем тулбаре над условием и рабочей областью, перед селектором
  режима. Вкладки видны и при скрытой панели; выбор вкладки открывает панель с её
  содержимым. Исходная вкладка — шаги; основная область — редактор.
  В Code условие доступно отдельно от вкладок и раскрывается/скрывается собственной кнопкой
  согласно [P2.1, R-06](p2-1-room-layout-modes.md); в Markdown оно скрыто, документ виден
  в основном редакторе. При включённой схеме [P2.4](p2-4-room-diagrams.md) холст
  занимает основную область, условие доступно как в Code. Четыре вкладки
  сохраняются при смене любого доступного режима.
- **R-03.** Resize панелей, включая высоту условия в Code, работает мышью и клавиатурой
  и соблюдает безопасные минимумы. Перетаскивание левого разделителя вправо расширяет
  боковую панель; влево — сужает. Условие не сдвигается при переключении вкладок.
- **R-04.** Layout state локальный, не синхронизируется на сервер и не влияет на других участников;
  при resize, zoom и переключении сохраняются draft, scroll, выбранный шаг и editor state.
- **R-05.** При входе, перезагрузке и переходе в другую комнату редактор открыт,
  в том числе в узкой раскладке с одной основной областью. После явного открытия
  вспомогательной вкладки в этой раскладке над содержимым доступна отдельная
  заметная основная кнопка «Вернуться к редактору» на всю ширину. Она доступна
  мышью и клавиатурой, возвращает фокус в редактор и сохраняет его документ,
  выделение и историю отмены. Дополнительная вкладка «Редактор» не появляется.
- **R-06.** Кнопка «Скрыть боковую панель» находится в её собственной шапке.
  После скрытия слева остаётся компактная полоса с «Показать боковую панель»;
  открытие восстанавливает выбранную вкладку, ширину и её черновики. Отдельной
  кнопки управления панелью в общем тулбаре нет; четыре вкладки остаются там по R-02.
  На узком экране открытие показывает последнюю вспомогательную область вместо
  редактора, скрытие возвращает редактор. Подпись и `aria-expanded` отражают
  фактическую видимость панели. Скрытые области, включая iframe, недоступны
  для фокуса. Настройка локальна, без записи на сервер/в browser storage,
  сбрасывается при перезагрузке/смене комнаты; условие управляется отдельно.
  Разворачивание схемы на всё окно определяет [P2.4 R-12](p2-4-room-diagrams.md).
- **R-07.** Вкладки и кнопки открытия/сворачивания имеют одинаковую высоту 36px
  по текущей теме; область нажатия не меньше видимой кнопки. Вкладки переносятся
  в два ряда при необходимости. После сворачивания фокус переходит на кнопку
  открытия в полосе, после открытия — на выбранную вкладку. На узком экране
  сохраняются редактор по умолчанию и заметная кнопка возврата по R-05.

## Приёмка и проверка

- **AC-01.** В Code, Markdown, диаграммах и доске область с доступным именем
  «Редактор» начинается с содержимого. Одноимённые заголовок и вкладка отсутствуют.
- **AC-02.** Чат, соседние панели и условие изменяют размер мышью и клавиатурой в безопасных границах.
- **AC-03.** При resize/zoom/переключении не теряются draft, scroll, выбранный шаг и editor state.
- **AC-04.** Во всех доступных режимах комнаты видны те же четыре вкладки. Отдельное условие
  видно в Code и включённой «Схеме» по P2.4, без скачков между вкладками и перекрытия внутренних элементов;
  его высота и раскрытое состояние сохраняются при Code → Markdown → Code.
  На коротком экране поля чата и заметок, условие в Code и действия доступны через прокрутку панели.
- **AC-05.** Узкое окно, перезагрузка после открытия чата и переход в другую
  комнату → редактор виден по умолчанию. Каждая из четырёх вкладок открывается
  явно, после чего полная кнопка возврата видна без горизонтальной обрезки в
  обеих темах; click/Enter возвращают редактор и фокус, сохраняя ввод и undo.
- **AC-06.** Широкое окно → скрыть/показать боковую панель мышью и клавиатурой:
  редактор расширяется, после возврата прежние вкладка, ширина, черновик и iframe;
  условие и другой участник не меняются, серверных записей нет. Кнопка полосы
  снова показывает панель; выбор видимой вкладки также открывает её содержимое.
  На узком экране доступны показ/скрытие и возврат;
  resize/reload соблюдают R-05 и не открывают скрытую область самопроизвольно.
- **AC-07.** В широкой комнате панель слева, редактор справа,
  кнопка сворачивания внутри панели; четыре вкладки остаются над рабочей областью
  перед селектором режима и доступны после сворачивания. Высота кнопок согласована. Сворачивание →
  компактная полоса слева; открытие мышью/клавиатурой восстанавливает вкладку,
  ширину, черновики и корректный фокус. Левый разделитель следует направлению
  указателя; узкое окно и 100–200% zoom не обрезают управление.
