# P0.3 Комната: вкладки и изменение размеров панелей

Цель: редактор остаётся центральной областью без лишней вкладки «Редактор», а вспомогательные области сохраняют доступность и изменяемые размеры.

Статус: реализовано и технически проверено; условие в Code определено [P2.1](p2-1-room-layout-modes.md),
продуктовый просмотр ожидается.
Актуализировано: 2026-10-04.

## Границы и требования

Входит: локальная геометрия панелей и доступность четырёх вспомогательных вкладок.
Права, общий режим и доставка документов определяются P2.1/P2.3; изменение размеров
не меняет серверные данные или раскладку других участников.

- **R-01.** Видимая вкладка «Редактор» не нужна, сам editor landmark/label сохраняется.
- **R-02.** Доступны четыре вкладки: шаги, заметки, чат, активность. По умолчанию выбраны шаги.
  В Code условие доступно отдельно от вкладок и раскрывается/скрывается собственной кнопкой
  согласно [P2.1, R-06](p2-1-room-layout-modes.md); в Markdown оно скрыто, документ виден
  в основном редакторе. Четыре вкладки сохраняются при смене режима.
- **R-03.** Resize панелей, включая высоту условия в Code, работает мышью и клавиатурой
  и соблюдает безопасные минимумы. Условие не сдвигается при переключении вкладок.
- **R-04.** Layout state локальный, не синхронизируется на сервер и не влияет на других участников;
  при resize, zoom и переключении сохраняются draft, scroll, выбранный шаг и editor state.

## Приёмка и проверка

- **AC-01.** В обычной комнате нет лишней вкладки «Редактор»; редактор имеет корректное accessible name.
- **AC-02.** Чат, соседние панели и условие изменяют размер мышью и клавиатурой в безопасных границах.
- **AC-03.** При resize/zoom/переключении не теряются draft, scroll, выбранный шаг и editor state.
- **AC-04.** В обоих режимах комнаты видны те же четыре вкладки. Отдельное условие
  видно только в Code, без скачков между вкладками и перекрытия внутренних элементов;
  его высота и раскрытое состояние сохраняются при Code → Markdown → Code.
  На коротком экране поля чата и заметок, условие в Code и действия доступны через прокрутку панели.
