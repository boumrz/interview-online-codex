### P1.3 Командная библиотека задач

Цель: командная библиотека задач работает отдельно от личной.

Готово:

- backend storage/API для активных командных задач:
  - `GET /api/teams/{teamId}/tasks?status=active|archived`;
  - `GET /api/teams/{teamId}/tasks?language=...&q=...`;
  - `POST /api/teams/{teamId}/tasks`;
  - `POST /api/teams/{teamId}/tasks/import-personal`;
  - `POST /api/teams/{teamId}/tasks/{taskId}/copy`;
  - `PATCH /api/teams/{teamId}/tasks/{taskId}`;
  - `POST /api/teams/{teamId}/tasks/{taskId}/archive`;
  - `POST /api/teams/{teamId}/tasks/{taskId}/restore`;
- командные задачи хранятся отдельно от `user_task_templates` и не подмешивают
  личную библиотеку владельца/участника;
- активный участник команды может читать и создавать командные задачи;
- создатель задачи или OWNER/ADMIN может редактировать, архивировать и
  восстанавливать командную задачу;
- владелец личной задачи может скопировать её в командную библиотеку без
  изменения личного оригинала;
- активный участник команды может скопировать доступную командную задачу без
  права редактировать оригинал;
- редактирование защищено `revision`/CAS и stale update возвращает
  `TEAM_TASK_REVISION_CONFLICT`;
- чужая/недоступная команда скрывается как `TEAM_NOT_FOUND`;
- UI вкладки «Библиотека» больше не показывает «Раздел готовится» и
  поддерживает создание, редактирование, архив/восстановление задачи, поиск,
  фильтр языка, импорт личной задачи по ID, копирование командной задачи и
  переключение active/archive;
- проверки:
  - backend `TeamTaskLibraryIntegrationTest` — зелёный;
  - frontend isolated E2E P1.3 — зелёный:
    - создание;
    - редактирование;
    - архив/восстановление;
    - импорт личной задачи;
    - копирование командной задачи;
    - поиск.

Что сделать:

- P1.3 MVP готов; следующая работа по задачам переходит в P1.4/P1.5.
- Без привязки задачи напрямую к треку/вакансии в P1.3: выбор задач будет
  решаться в сценарии создания командного интервью.

Acceptance:

- сотрудники команды могут читать доступные задачи;
- автор/админ редактирует по правам;
- неавтор без прав может сделать копию, но не перезаписать оригинал;
- правка библиотечного оригинала не меняет snapshot уже созданного интервью.

## Корректировка по продуктовой проверке 2026-09-23

- В командной библиотеке задачи и наборы показаны в отдельных вкладках; переключение не требует прокрутки всей страницы.
- Импорт личной задачи открывается в модальном окне. Создание задачи также открывается поверх списка, чтобы не занимать место постоянно.
- Вкладки «Задачи / Наборы задач» и «Активные / Архив» являются двумя
  различимыми группами в одной панели вместе с действиями создания и импорта.
  На широкой странице они размещаются в одну строку, на узкой переносятся
  группами. Создание выделено цветом и плюсом.
- Фильтр языка и кнопки обновления имеют явную форму элементов управления.

## Корректировка интерфейса 2026-09-23

- «Копировать» кладёт название, описание, язык и стартовый код задачи в буфер обмена для передачи другому человеку. Список задач и база данных не меняются; действие дублирования в интерфейсе не предлагается.
- При наведении активная вкладка становится темнее, сохраняя выбранное состояние. Поиск компактный и находится в строке вкладок на широкой странице.
- В пустом состоянии и карточках библиотеки нет двойных декоративных рамок.
- Кнопка создания расположена рядом с вкладками и имеет общий с другими действиями создания синий цвет.

## Передача задач между пользователями

- «Копировать» сохраняет переносимые данные задачи (название, язык, описание и стартовый код), без внутреннего ID. Данные можно отправить другому человеку и вставить в «Импортировать» личной или командной библиотеки.
- Импорт в команду по ID собственной личной задачи сохранён. Для обмена между аккаунтами используется копирование и вставка данных.
- У архивной командной задачи нет действия «Копировать».
- Личная библиотека содержит действия «Копировать» у задачи и «Импортировать» рядом с созданием задачи.

## Уточнение удаления 2026-09-23

- У командной задачи есть отдельное действие «Удалить» с подтверждением, доступное автору или OWNER/ADMIN. Сервер отклоняет удаление с `409`, если задача входит в набор или в задачи интервью по треку/вакансии. Архивирование и восстановление остаются отдельными действиями.
