### P1.4 Наборы задач

Цель: переиспользуемые наборы задач работают в личной и командной библиотеке.

Уже сделано:

- личные наборы задач существуют как «пресеты» и доступны во вкладке
  «Наборы задач» личной библиотеки;
- личный набор можно создать, отредактировать и сохранить порядок задач;
- личный набор можно выбрать при создании личного интервью;
- backend lifecycle для личных наборов:
  - `GET /api/me/presets?status=active|archived`;
  - `POST /api/me/presets/{presetId}/copy`;
  - `POST /api/me/presets/{presetId}/archive`;
  - `POST /api/me/presets/{presetId}/restore`;
- личные наборы получили `status` и `revision`;
- update личного набора принимает `revision` и stale update возвращает
  `PRESET_REVISION_CONFLICT`;
- архивные личные наборы не попадают в default active-list и не выбираются при
  создании личного интервью;
- UI личных наборов поддерживает active/archive, копирование, архив и
  восстановление;
- backend storage/API для командных наборов задач:
  - `GET /api/teams/{teamId}/task-sets?status=active|archived`;
  - `POST /api/teams/{teamId}/task-sets`;
  - `PATCH /api/teams/{teamId}/task-sets/{setId}`;
  - `POST /api/teams/{teamId}/task-sets/{setId}/copy`;
  - `POST /api/teams/{teamId}/task-sets/{setId}/archive`;
  - `POST /api/teams/{teamId}/task-sets/{setId}/restore`;
- командный набор хранит порядок задач, `status`, `revision`, автора и
  отделён от личных пресетов;
- активный участник команды может читать, создавать и копировать командные
  наборы;
- создатель набора или OWNER/ADMIN может редактировать, архивировать и
  восстанавливать набор;
- stale update командного набора возвращает `TEAM_TASK_SET_REVISION_CONFLICT`;
- UI командной библиотеки показывает блок «Наборы задач» и поддерживает
  создание набора из чекбоксов задач, копирование, архив и восстановление;
- UI командной библиотеки поддерживает редактирование командного набора:
  переименование, изменение состава через чекбоксы и ручное перемещение задач
  выше/ниже с сохранением нового порядка;
- активный участник может скопировать свой личный набор в команду по ID:
  сервер создаёт командные копии задач, сохраняет порядок и заводит новый
  командный набор без ссылки на личные `taskTemplateId`;
- экран подготовки командного интервью загружает активные командные наборы,
  позволяет выбрать набор и явно показывает развёрнутый порядок задач;
- при создании командного интервью сервер сохраняет `team_task_set_id`,
  `team_task_set_revision` и snapshot задач в `room_tasks`;
- snapshot воспроизводит порядок набора и не меняется после правки командной
  библиотеки;
- проверки:
  - backend `UserPresetLifecycleIntegrationTest` — зелёный;
  - backend `TeamTaskSetIntegrationTest` — зелёный;
  - frontend isolated E2E P1.4 personal sets — зелёный:

    - восстановление;
    - отображение `revision`.
  - frontend isolated E2E P1.4 team task sets — зелёный:
    - создание набора из командных задач;
    - копирование;
    - архив;
    - восстановление.
  - frontend isolated E2E P1.4 team task set edit/reorder — зелёный:
    - переименование;
    - ручное изменение порядка;
    - PATCH отправляет актуальный `revision` и новый список `taskIds`.
  - backend `TeamTaskSetIntegrationTest` import personal preset — зелёный:
    - snapshot личных задач в командные задачи;
    - порядок набора сохраняется;
    - чужой или архивный личный набор не раскрывается и не импортируется.

- UI работает на tablet/short viewport.

## Корректировка по продуктовой проверке 2026-09-23

- Командные наборы доступны отдельной вкладкой библиотеки. Создание командного набора и импорт личного набора открываются в модальных окнах; успешное действие закрывает окно и обновляет список.

## Корректировка интерфейса 2026-09-23

- «Копировать» командный набор записывает его название и упорядоченный список задач в буфер обмена, не создавая дубликат в библиотеке.
- «Копировать» личный набор работает так же: текст для передачи человеку попадает в буфер обмена, новый набор не появляется.
- Список наборов и пустое состояние не обрамляются вложенными друг в друга карточками.
- Личная библиотека называет эту сущность «набором» во вкладке, заголовке и диалогах; синяя кнопка создания стоит рядом с вкладками.

## Уточнение удаления 2026-09-23

- Личный и командный наборы можно удалить после подтверждения. Для командного набора действие доступно автору или OWNER/ADMIN; набор, уже использованный в интервью, сервер отклоняет с `409`. Задачи, входящие в удалённый набор, сохраняются.

## Передача наборов между пользователями

- «Копировать» личный или командный набор сохраняет переносимые данные: имя, полное содержимое каждой задачи и их порядок. Внутренние ID не передаются.
- Получатель вставляет данные через «Импортировать» в личной или командной библиотеке. Импорт создаёт независимые задачи и набор в пространстве получателя. Импорт своего личного набора в команду по ID сохранён.
- У архивных наборов нет действия «Копировать». Если в активном командном наборе задача уже архивирована, копирование набора выдаёт понятную ошибку.
- Неверный или устаревший текст в поле импорта объясняет, что требуются данные из новой кнопки «Копировать».
- Пустое состояние личных наборов не обрезается скруглением контейнера.
