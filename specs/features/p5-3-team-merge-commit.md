### P5.3 Commit объединения

Статус: **снято с продукта**. Ниже сохранено описание прежней реализации; новые commit-операции недоступны через API. Переадресация уже объединённых команд продолжает работать.

Цель: подтверждённое объединение сохраняет историю, права и ссылки.

Реализовано:

- atomic approved-plan commit;
- перенос FK без смены IDs/snapshots;
- MERGED tombstone source team;
- redirect старых room/scope links;
- revocation старых приглашений;
- invalidation sessions/cache/export projections.

Старые ссылки разрешаются через всю цепочку объединений до действующей команды;
после успешного commit сервер сбрасывает локальный кэш realtime-комнат. Перед
переносом проверяются актуальность плана, права обоих владельцев и отсутствие
живых SSE-сессий и ожидающих записей в комнатах исходной команды.
Выход из комнаты требует токен текущего SSE-подключения: поздний запрос старой
вкладки не может отключить новую сессию и обойти проверку живой комнаты.

Запуск закрыт отдельным feature flag `FEATURE_TEAM_MERGE_COMMIT`, выключенным по умолчанию. Активность комнаты теперь публикуется в общей PostgreSQL-таблице каждым backend-процессом при SSE admission, продлевается во время живой сессии и ожидающих записей и проверяется под блокировкой строк комнат перед commit. Потеря аренды закрывает локальный stream; после аварийного завершения процесса запись перестаёт блокировать commit через 60 секунд. Локальная проверка ожидающих записей дополнительно учитывает запросы и фоновые сохранения в исполнении. Межпроцессная доставка realtime-событий остаётся отдельным вопросом конфигурации транспорта и маршрутизации; общий учёт здесь обеспечивает безопасность именно commit объединения.

Проверка: PostgreSQL integration на атомарный перенос, повтор с тем же ключом, старые ссылки и права, коллизии, устаревание и конфликт участия; browser E2E на согласование, финальное подтверждение и переход из старого пространства.

Исторический acceptance (неактивен):

- после успеха есть одно итоговое пространство;
- старая команда не работает отдельно;
- старые ссылки ведут в итоговую команду только после проверки актуального доступа;
- личные/Orbit данные не затрагиваются.

## Корректировка по продуктовой проверке 2026-09-23

- Новые операции объединения команд недоступны. Переадресация уже объединённых команд сохраняется как совместимость для старых ссылок.
