## Дополнительные регрессии общего набора

- Первоначальная отправка SSE больше не удерживает транзакцию и соединение базы;
  позднее закрытие старого подключения не удаляет новое.
- При frozen отменённые записи чата/заметок возвращаются как локальный
  неподтверждённый ввод; следующий черновик сохраняется. При отзыве manager роли
  защищённые данные очищаются. Queued-notes 4/4 и Markdown 9/9 после этой правки.
- В выборе нанимающих удаление другого выбранного пункта не очищает введённый UUID;
  обычное удаление текста и Escape сохраняют ожидаемое поведение.
- Повтор неудачного переименования команды использует прежний ключ/тело запроса,
  если название не изменено; новый ввод создаёт новое намерение.
- Pagination адаптер согласует число страниц и текущую страницу с Ant Design;
  в каталоге из 26 участников и HR списке из 21 интервью доступна вторая страница.
- Enter на первоначально сфокусированном пункте навигационного меню открывает
  его ссылку; обычный и модифицированный клик сохраняют адрес и поведение.
- Быстрый Escape после открытия либо Arrow/Home/End больше не отдаёт фокус
  закрывающемуся меню. Два независимых browser RED показали поздний autofocus
  Dropdown и отдельный отложенный переход rc-menu. Собственный autofocus
  отменяется при закрытии; сохранённый закрытый список становится inert,
  повторное открытие создаёт новое меню. Target 2/2 проверяет native Tab/ShiftTab,
  новый focus intent и немедленное открытие, включая идентичность старого/нового
  DOM списка. Независимый review — APPROVE; полный navigation 109/109 — PASS.
- Успешное изменение участника/владельца сохраняет подтверждение и focus при
  обновлении прав в той же команде. Во время проверки и после её ошибки
  управляющие действия закрыты; focus не обрывает уже выполняющуюся проверку.
  Потеря capability закрывает защищённые диалоги/черновики; поздний callback
  другого аккаунта/команды не запускает запросы в новом контексте.
- Обновление названия той же задачи сохраняет данные доставки Yjs. Собственная
  ожидающая запись со старой базой и snapshot heartbeat последнего автора
  сохраняют текст; чужой устаревший snapshot и запись finished candidate
  отклоняются. PostgreSQL: новый regression 4/4 (подтверждён RED до правки),
  Markdown 4/4 и relay policy 1/1 после правки. Это отдельный установленный
  дефект, а не доказанная причина прежней нестабильности lifecycle-теста.
- Блокировка фоновой записи одной комнаты больше не удерживает общий saver:
  принятый snapshot сохраняется в памяти сервера до commit, занятая строка
  допускает повтор без удержания соединения. Новый PostgreSQL regression
  воспроизвёл RED: B relay за 8ms, но B не сохраняется за 3s при заблокированной A.
  Целевой PostgreSQL 7/7 GREEN и независимый review — APPROVE, включая
  новый snapshot, frozen/archive/смену команды/удаление исходной задачи и
  retained activity/lease после закрытия последнего SSE. Чистый общий backend — 380/380.
- Узкое окно 512×682 с длинной историей чата сохраняет доступность поля ввода:
  воспроизведена постоянная обрезка, затем compact composer применён к узкому
  низкому окну; 24 варианта geometry и многострочные черновики проверены заново.
- Поле ссылки приглашения не обрезается при фокусе в окне 384×512.
- Кнопка повтора создания команды сохраняет доступное имя «Повторить», пока
  анимация индикатора загрузки завершается. После потерянного ответа повтор
  переиспользует ключ и тело команды. Реальная нестабильность воспроизведена
  без tracing; после правки пять повторов и полный workspace набор 49/49 — PASS.
- Прямой вход в admin раздел ожидает профиль; подтверждённый non-admin не получает
  защищённую страницу.
- Вход и регистрация публикуют сессию после свежего профиля. Удержанный profile
  GET воспроизвёл преждевременный переход и сброс входа при быстром hard navigation.
  Pending охватывает обе стадии; после profile failure доступен повтор без
  дублирования регистрации. Поздний ответ проверяет текущую попытку, аккаунт,
  storage и адрес; уход/pagehide отменяет попытку. Новые API-backed проверки
