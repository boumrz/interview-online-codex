# Длинные названия в селекторах — 05.10.2026

Запрос пользователя: длинное название команды не должно создавать
горизонтальную прокрутку; названия в селекторах сокращаются многоточием
до доступной ширины. Договор: UI.2 R-05/R-06/AC-02, P0.2 R-01.

## Изменение

- Список команд ограничивает grid-строку и flex-название доступной шириной;
  отметка выбранной команды сохраняет размер. Горизонтальная прокрутка
  исключена, вертикальная и фиксированное действие создания сохраняются.
- Общие Select/MultiSelect ограничивают ширину внутренних flex-элементов,
  названий options и выбранных chips. Стрелка, очистка и снятие выбора остаются
  доступными. Управляемая библиотекой вертикальная прокрутка не меняется.
- Составные пункты задач сокращают название, сохраняя язык и метки.
  Вложенное имя в подборе нанимающего также ограничено шириной dropdown.
- CSS сохраняет полный текст в DOM/доступном имени и существующем title;
  поиск и выбор продолжают использовать полное значение. API и права не меняются.

## Проверка

Целевой браузерный файл использует настоящие production компоненты и
browser-only API фикстуры в изолированном runtime. Пользовательское приложение
и БД не используются для тестовых данных. Проверяются light/dark на 768/1366px,
длинные слова и названия с пробелами до 200 символов, открытые списки/закрытые
поля/chips, вертикальная прокрутка, отметка/стрелка/удаление, поиск и клавиатура.

Поведенческий RED подтверждён одним полным сценарием: ширина прокрутки списка
команд 1822px при доступных 320px, отметка выбора выходила за границу; названия
задач и вложенный текст нанимающего не имели корректной обрезки. Поиск, выбор и
вертикальная прокрутка в этом прогоне работали. Первичные ошибки locator helpers
не считаются поведенческим RED.
