# Непрерывный предпросмотр Markdown — 31 октября 2026

Исправлена оставшаяся регрессия после удаления статуса загрузки: при каждом
вводе hook очищал HTML, а компонент убирал содержимое из DOM. Прежний тест
проверял отсутствие статуса и размеры панели, поэтому пропустил исчезновение текста.

Теперь при обработке новой версии того же документа остаётся последний успешный
предпросмотр, с прежним DOM-контейнером и прокруткой. Новый результат заменяет
содержимое без промежуточного пустого кадра. Пустой исходник сразу очищает preview.
При смене комнаты, аккаунта, UUID задачи или публичного/приватного документа
прежний HTML сразу скрывается; поздние ответы его не возвращают. Ключ доступа
непрозрачен, не содержит tokens и не записывается в storage. Ошибка Worker и
повторная попытка остаются видимыми. CodeMirror и Yjs редакторы не перемонтируются.

Контракт: P2.1 R-09 / AC-15. Реализовано и технически проверено;
продуктовый просмотр пользователем ожидается.

## UI проверка

На предыдущем коде шесть сценариев дали RED именно по удалению preview DOM:
18 тестов, 12 PASS / 6 FAIL, без setup ошибок. На исправлении:

- 22 Markdown browser сценария: обе темы, компактный/развёрнутый/общий Markdown
  режим, 1250 строк, задержанные ответы настоящего Worker и два полных цикла
  ввода/получения HTML. MutationObserver проверяет отсутствие удаления содержимого,
  rAF — пустых кадров, скрытия через CSS и нулевой видимой области. DOM и scroll
  сохраняются до и после новых ответов.
- Проверены смена документа без remount, одинаковый текст разных документов,
  committed A → pending B → pending A, очистка → настоящий Undo, поздние ответы,
  реальная ошибка Worker → видимая ошибка → успешный retry текущего текста.
- Четыре новых real API UI сценария: публичный/приватный редактор × light/dark,
  настоящий посимвольный ввод, задержка Worker, непрерывно видимое содержимое,
  сохранение на сервере, доставка кандидату только публичного текста.
