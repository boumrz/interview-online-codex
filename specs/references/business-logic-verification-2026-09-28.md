## Реализованный scope

| Запрос | Результат |
| --- | --- |
| Ссылка командного интервью для кандидата | Гость и чужой аккаунт входят кандидатом; потеря членства сохраняет публичный вход без управляющих прав. Проверены перезагрузка, SSE, завершённая комната и запись кода в ранее перенесённой комнате. |
| Общие возможности команды | Каждый ACTIVE участник видит кандидатов и управляет интервью без личной настройки нанимающего и отдельного назначения. Внешний нанимающий приглашается по UUID к конкретному интервью; активные участники команды не предлагаются для этого назначения. |
| Треки и вакансии | Оба списка фильтруются сервером до пагинации; Excel получает те же параметры. Архивные справочники доступны для исторических интервью, смена фильтров отменяет устаревшее скачивание. |
| Комментарий Excel | Добавлена отдельная колонка со всей сохранённой историей хоста, шагами и блоками. Комментарий к решению сохранён отдельно. Длинные записи полностью вынесены на лист «Комментарии», emoji не разрываются. Подтверждённые сервером записи гостевого хоста сохраняются и после привязки аккаунта. |
| Настройки команды | Участники, приглашения и управление командой объединены в «Настройки команды». Старый маршрут `/members` перенаправляется в `/settings`. |
| Выгрузка заметок комнаты | Реальные Markdown/PDF файлы содержат сохранённые заметки после перезагрузки. Ошибка подготовки PDF видна и позволяет повторить попытку. Локальный dev заранее компилирует импортируемые модули, поэтому первый экспорт после перезапуска не зависает. |

## Ограничение старых данных

В старых гостевых записях сохранялся только переданный клиентом идентификатор автора, без подтверждения роли хоста. Надёжно отличить такие записи от записей другого гостя невозможно. Они остаются в комнате и доступны своему автору, но автоматически не включаются в Excel как заметки хоста. Новые записи хоста получают серверное подтверждение; старая история авторизованного владельца сохраняется в выгрузке.
