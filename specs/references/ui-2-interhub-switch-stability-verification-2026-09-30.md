# InterHub: название, стабильность пространства и интерактивные курсоры

Дата: 2026-09-30. Дополнение к [UI.2](../features/ui-2-usability-theme-polish.md) и [P0.2](../features/p0-2-workspace-navigation.md).

## Реализовано

- InterHub и монограмма IH в публичном интерфейсе, входе, личном/командном пространстве, вкладке и метаданных приложения. Названия frontend/backend пакетов, Maven/Gradle и Docker JAR согласованы. Актуальная документация и новые имена демозаписей используют InterHub.
- Сохранены идентификаторы существующих данных и инфраструктуры: базы, контейнеры, домены/пути, namespaces/classes, ключи темы/восстановления/приглашений, формат импорта и observability service key. Исторические материалы не переписаны.
- Первый переход между личным и командным пространством сохраняет уже показанный интерфейс до загрузки кода страницы. React transition применяется только к навигации селектора и успешному созданию команды; выход и защитные перенаправления остаются немедленными.
- Одинаковые размеры бренда и место навигации устраняют сдвиги шапки при проверке прав, включая вторую строку на tablet. Нейтральный каркас раздела сохраняет положение заголовка. Авторизация и защита от запоздалых ответов не изменены; старые данные команды скрыты при смене контекста.
- `scrollbar-gutter: stable` предотвращает изменение ширины при переходе с длинной страницы на короткую.
- Общий pointer для активных семантических действий и календарных полей. Отключённые элементы, ввод текста и resize сохраняют соответствующий курсор.

- `e2e-interactive-cursors.mjs` —4/4: даты, действия, меню, вкладки, selectors/options/clear/remove, checkbox/radio/switch, text inputs, disabled и resize.
- `e2e-interhub-branding.mjs` —3/3; регрессии header hover/selector/keyboard —3/3. Суммарный финальный прогон этих четырёх файлов после готовности перезапущенного приложения —17/17.
- Целевые реальные API сценарии старого командного набора —3/3: поздний ответ Atlas, back/forward, смена аккаунта. Два теста теперь ожидают подтверждённое название команды перед продолжением, вместо проверки только URL.
- Целевые layout-регрессии обеих тем и разных ширин —3/3. Typecheck, production build, Maven validate, diff-check PASS. Существующие предупреждения сборки о размерах chunks/шрифтов остаются.
- Независимый обзор финального варианта —APPROVE; отдельно повторены задержанный chunk и выход —2/2.

Полный исторический набор не заявляется зелёным: расширенная AC-02 history/focus матрица содержит старое ожидание скрытия подтверждённого черновика сразу при background refresh и прежнее доступное имя alert. Текущий контракт сохраняет черновик при background-проверке до подтверждённого отказа; изменение этой политики в запрос не входит. Новые проверки смены контекста и403 проходят.

Проверено в Chromium. Содержимое popup нативного календаря принадлежит браузеру и недоступно DOM-тестам; проверены календарное поле/курсор и ввод даты.

## Локальный запуск

Окончательная версия запущена на frontend5173/backend8080 с прежним локальным FEATURE_TEAM_WORKSPACES=true. HTTP200 и `/api/public/health` со status=ok подтверждены. Существующие серверные ключи переиспользованы; flags по умолчанию не изменены. Продуктовый просмотр остаётся за пользователем.
